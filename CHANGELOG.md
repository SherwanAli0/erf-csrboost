# Changelog

## FixYourDataset 2.0.1 / rare-event-eval 0.3.1

- Add a private usage dashboard with UTC date filters, recognised source-link labels,
  daily visitor estimates, coarse device/browser families and explicit owner/test/bot exclusions.
- Count new workbench upload, job, report and data-tool requests without storing their contents.
- Preserve historical usage rows and distinguish missing attribution from known sources.
- Carry only allowlisted campaign labels in browser memory for same-origin API calls.
  No visitor cookies, external analytics service or new hosting resources.


## FixYourDataset 2.0 / rare-event-eval 0.3.0

- Added a maintained workbench with recorded and fictional examples, an explicit analysis flow,
  browser-only saved-prediction evaluation, accessible reports and separate research evidence.
- Connected mixed-type application training to the reusable evaluation core and named model recipes.
- Added FastAPI, private capability-owned jobs, bounded workers, cancellation, expiry and typed errors.
- Integrated training exports, a controlled Leakage Lab and new-row scoring with explicit labels and
  opt-in row downloads. Preserved the previous interface and legacy routes for compatibility.
- Added standalone HTML/JSON, effective configuration and bounded replay bundles without raw rows.
- Added locked environments, a wheel-based container, cross-platform CI and resource-constrained checks.
- Preserved historical research procedures/results, submitted work and third-party credits. Application
  comparisons use their own procedure and do not reproduce the historical research tables.
