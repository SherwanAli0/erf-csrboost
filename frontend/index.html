Fix Your Dataset.
ML honesty auditor

Find the hidden ways your ML dataset can mislead you.

A common mistake is to balance the data before splitting it, which lets the test set leak into training and makes the score look better than it really is. This tool locks the test set and shows you the honest score next to the optimistic one. It also puts ERF-CSRBoost, an experimental, unpublished extension of CSRBoost, head to head with the published IEEE method, judged only on data the models never saw.

The server does keep a usage event for each visit and analysis: the time, the action, the demo name (or the word "upload"), the referrer, and a visitor hash that changes daily. How thorough should the check be?

To judge the method fairly we split your data into folds: train on part, test on the rest, then rotate so every row gets tested. We average across all folds, so one lucky or unlucky split cannot fool the result. More folds means a more reliable answer, but it takes longer.
